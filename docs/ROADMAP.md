# Próximas entregas

Este roteiro distingue o código inicial das evoluções propostas. Marque uma
entrega como concluída somente depois de executá-la e reunir a evidência indicada.

| Etapa | Estado inicial | Critério de conclusão |
| --- | --- | --- |
| Landmarks em webcam | Código disponível; testar no computador local | Zero, uma e duas mãos e saída correta |
| Gestos do modelo pronto | Código disponível; testar no computador local | Nomes e rejeição visíveis |
| Escrita no ar | Código disponível; testar no computador local | Traços separados, pausa e cursor coerente |
| Exportação da escrita | Código disponível; testar no computador local | PNG limpo e JSON com limites dos traços |
| Busca de imagem por pose corporal | Modo posematch implementado; testar webcam local | Pose utilizável seleciona referência e ausência limpa o painel |
| Catálogo próprio de poses | Indexador disponível | Imagens válidas indexadas, referências portáveis e origem documentada |
| Demonstração própria | Pendente | Vídeo autorizado da versão executada |
| Estabilização dos rótulos de gestures | Pendente | Medir oscilação e atraso com uma mão |
| Associação de duas mãos | Pendente | Histórico não migra indevidamente entre mãos |
| Regra de pinça | Pendente | Testar distâncias e orientações definidas |
| Coletor de landmarks | Pendente | Metadados e apresentações identificadas |
| Classificador próprio | Pendente | Treino separado e avaliação por grupos |
| Reconhecer dígitos escritos | Pendente | Um dígito confirmado, dataset próprio e teste por pessoa |
| Reconhecer letras e palavras | Pendente | Avaliar caracteres, limites e ambiguidades |
| Interação útil | Pendente | Ação confirmada uma vez e possibilidade de pausa |
| Demo web | Opcional | Captura autorizada e inferência no navegador |
| Classificador de poses corporais | Opcional, além da busca geométrica atual | Classes definidas, dataset e avaliação próprios |

O primeiro uso concreto agora inclui escrita no ar. Depois de validar a caneta,
escolha entre reconhecer números e letras ou construir uma tela experimental de
seleção por pinça para o Intuição. Na integração com jogos, mantenha uma alternativa
por mouse e meça tempo e erros de interação.
